# Quản lý vé máy bay — phần Thành viên 4

Bốn lớp quản lý mảng trong đồ án Java OOP: `QuanLyVe`, `QuanLyHanhKhach`, `QuanLyDaiLy`, `QuanLyChuyenBay`. Xem [danh sách chức năng](CHUC_NANG_THANH_VIEN_4.md).

## Cách ghép vào project nhóm

1. Chép bốn file `.java` vào thư mục chứa mã nguồn của nhóm (cùng package với các lớp dữ liệu, hoặc chỉnh dòng `package` cho thống nhất).
2. Tạo các lớp dữ liệu và getter/setter đúng tên trong [ghi chú ghép nhóm](GHI_CHU_CHO_NHOM.md).
3. Sau khi ghép, biên dịch và chạy thử các chức năng từ menu của nhóm.

Đây là phần quản lý mảng, chưa phải chương trình chạy độc lập. Phần đặt vé cần dùng `demVeConHieuLucTheoMaChuyenBay()` để không tính vé đã hủy; phần đọc/ghi file cần lưu trạng thái hủy.
